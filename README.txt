PAKET HERO MLBB UNTUK WEBSITE ZUBAIR

Cara pakai:
1. Ekstrak ZIP ini.
2. Klik dua kali DOWNLOAD_HERO.bat.
3. Tunggu sampai proses selesai.
4. Empat file PNG akan muncul di folder yang sama.
5. Salin empat file PNG tersebut ke folder utama repository GitHub Pages.

Nama file sudah disesuaikan dengan JavaScript website:
- hero-alfa.png = Nana, Slumber Party
- hero-faruk.png = Balmond, Power Source (skin, bukan default)
- hero-zubair.png = Ling, Serene Plume
- hero-anak-e-pak-yon.png = Sun, Monkey King

CATATAN PENTING:
Gambar sumber adalah splash art resolusi tinggi dan masih memiliki latar belakang.
Paket ini belum menghapus latar belakang dan belum menghasilkan PNG transparan.
Balmond Power Source dan Sun Monkey King adalah gambar skin; koleksi sumber ini
tidak menyediakan file bernama Default untuk keduanya.
